# SHAE — Deutsche Dokumentation

## Installation
Führe `scripts/install.sh` aus, um das ClojureScript-Dashboard zu installieren.

## Plattform
Web-App (ClojureScript, kompiliert zu JavaScript).

## Build
`clj -M:build`

## Release
GitHub Release v0.1.0 verfügbar.

## Design
Folgt dem SHAE Field Manual: warm paper #F2EEE5, ink #191712, oxide #B3341B, 0px Radius, 1px Rahmen.
