# SHAE ClojureScript Interactive Dashboard

An interactive dashboard written in ClojureScript.

## Features
- Real-time metrics display
- Interactive charts
- Live log streaming
- Reactive UI with Reagent
- Compiles to JavaScript

## Install
```bash
./scripts/install.sh
# Or manually:
clj -M:build
shadow-cljs watch app
```
